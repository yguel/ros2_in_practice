1.1. Installation of ROS2

There are several types of installation possible:

  1. Installation using docker. This is the simplest and works on windows, mac, and linux.

  2. Installation using precompiled packages (deb). This is the fastest and works very well on linux Ubuntu and can be adapted for other linux distributions.

    1. Installation using precompiled packages (deb) with a real-time kernel.This is the one we should prefer to work with a robot and it mainly works on linux Ubuntu, but can be adapted for other linux distributions.

  3. Installation using the source code. This is the most complicated and longest to install, it works on Ubuntu linux and can be adapted for other linux distributions, and with more difficulties and limitations on windows and mac.

Follow the instructions at the following address: https://docs.docker.com/desktop/setup/install/linux/

In a terminal

mkdir -p ~/ros2_course_docker_data

Now you can launch the docker container:

In a terminal

docker run -p 6080:80  -v "/home/YourUser>/ros2_course_docker_data:/home/ubuntu/ros2_course" --shm-size=1064m yguel/ros2_in_practice:humble

Follow the instructions at the following address: https://docs.docker.com/desktop/setup/install/windows-install/

Create a workspace directory for the ROS2 project that will be sharedbetween the host and the docker container

Create the directory: C:\Users\<YourUser>\Documents\ros2_course_docker_data

Now you can launch the docker container:

In a terminal of the docker-desktop program:

docker run -p 6080:80  -v "C:\Users\<YourUser>\Documents\ros2_course_docker_data:/home/ubuntu/ros2_course" --shm-size=1064m yguel/ros2_in_practice:humble

In a window of your web browser, open the following URL: http://localhost:6080. You should see a NO VNC window, just click to connect and you should see an ubuntu desktop like in the Figure 1.1 below:

You can now open a terminal and run ROS2 commands.

To install ROS2, it is recommended to follow the official instructions from the ROS2 documentation for Ubuntu

Setting up commands to facilitate the use of ROS2

To speed up the compilation and execution processes, we will use bash macros that make it easier when using the ROS2 tool suite centered around colcon.

Open your ~/.bashrc file with vscode:

code ~/.bashrc

Add the following lines at the end of the file:

1.1.1. First installation check

Verify that the ROS2 installation was successful by running the following commands in a first terminal to launch a publisher node (talker) written in C++:

ros2_humble
ros2 run demo_nodes_cpp talker

and in a second terminal, run the following command to launch a subscriber node (listener) written in Python:

ros2_humble
ros2 run demo_nodes_py listener

If you see the message “I heard” followed by a number, it means that the ROS2 installation was successful.

Exercise 1.1 (Bien démarrer …)

Install ROS2 on your machine and verify the installation by running the commands above. If you encounter any issues, feel free to ask questions on the issues page of the course GitHub.

1.2. Creating a workspace

A ROS2 project is compiled and executed in what is called a workspace, often abbreviated as ws, which contains a src directory that holds the ROS2 packages you will create or use.

On your linux system (Docker or native), create a workspace directoryfor the ROS2 project:

mkidr -p ~/ros2_course/ros2_ws/src

We will now use a ROS2 package that we will install in the src directory of your ROS2 workspace.

cd ~/ros2_course/ros2_ws/src
git clone https://github.com/yguel/scara_tutorial_ros2.git

1.2.1. Testing your installation

The command defined in the .bashrc file ros2_humble allows you to load the ROS2 environment for the humble distribution. This command should be executed every time you open a new terminal.

ros2_humble
sudo apt-get update -q

Note

You can verify that you have successfully loaded the ROS2 environment for the humble distribution by running the following command:

echo $ROS_DISTRO

Note

To load another ROS2 distribution, you can define a new command in your .bashrc file by replacing humble with the name of the distribution you want to load. This has already been done for the jazzy distribution (command ros2_jazzy).
Of course, for this to work, the distribution must be installed on your machine.

The command defined in the .bashrc file ros2_build allows you to compile the packages in your ROS2 workspace and load the environment variables necessary to run the nodes of these packages.

Compile your ROS2 workspace:

ros2_build

If you encounter errors, make sure you have followed the previous instructions correctly.
